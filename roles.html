角色學習地圖

想參與打造這樣一套系統？這裡列出每個角色要學什麼 —— 以及學到什麼程度。

挑一個你想成為的角色，往下看它的技能清單。每項技能的標籤代表你要鑽多深：只要了解、會用、能從零實作、還是要精通。

學到什麼程度？了解懂概念與取捨，不必動手會用能用現成工具完成任務實作能從零打造、除錯、整合精通能設計、最佳化、教別人
architecture

系統架構師

設計整套安全、可擴充的系統與其取捨。

  • 系統設計與取捨精通
  • 隔離模型（namespace / seccomp / cgroup）實作深到足以選對組合
  • 分散式系統與擴充（控制／資料平面）實作
  • 威脅模型會用
  • 容器 vs microVM 取捨（gVisor / Firecracker）會用
  • 可觀測性設計會用
terminal

後端 / 平台工程師

實作任務管理器與沙盒執行層。

  • Linux 系統程式設計（行程、syscall）實作
  • Namespace / cgroup API（clone、unshare、cgroupfs）實作
  • 撰寫 seccomp-BPF 過濾器實作
  • 任務佇列與排程實作
  • 容器執行期（runc / containerd）會用
  • Go / Rust / C（至少一種）實作
shield_person

安全工程師

強化隔離、做威脅模型、防止沙盒逃逸。

  • Linux 安全模型（capabilities、LSM、seccomp）精通
  • 沙盒逃逸與攻擊面實作
  • 政策：seccomp / AppArmor / SELinux實作
  • 威脅模型與紅隊演練實作
  • microVM 隔離（Firecracker / KVM）會用
  • 弱點研究與 CVE 追蹤會用
cloud_sync

DevOps / SRE

部署、擴充、監控並負責 on-call。

  • 容器編排（Kubernetes）實作
  • CI/CD 與基礎設施即程式碼（Terraform）實作
  • 可觀測性（指標 / 日誌 / 告警）實作
  • cgroup 資源配額調校會用
  • 執行節點自動擴縮實作
  • 事件應變與 on-call會用
web

前端工程師

打造上傳、啟動、結果呈現的介面。

  • HTML / CSS / JavaScript 基礎精通
  • 前端框架（React / Vue 其一）實作
  • 即時更新（WebSocket / SSE 顯示任務狀態）實作
  • REST API 串接實作
  • 前端資安（XSS、輸出跳脫）會用
  • UX 與無障礙會用
